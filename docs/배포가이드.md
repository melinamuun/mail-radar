## 1. 본체 워크플로 임포트

1. n8n → 좌상단 메뉴 → **Import from File**
2. `n8n/inbox-dashboard-n8n-workflow.json` 선택
3. 5노드 확인: Schedule → Compute Window → Gmail 수신 조회 → Build Dashboard → Gmail 발송

## 2. Gmail OAuth2 자격증명 (2노드, 동일 자격증명)

1. **Gmail 수신 조회** 노드 → Credential → Create New → OAuth2 인증(브라우저 로그인·동의)
2. **Gmail 발송(본인)** 노드 → 방금 만든 **같은 자격증명** 선택
- 스코프: 읽기(`gmail.readonly`) + 보내기(`gmail.send`), 또는 통합 `gmail.modify`

## 3. selfEmail 확인

- **Compute Window** 노드 코드 하단 `selfEmail: 'soobin7612@gmail.com'` — 받는 주소 변경 시 여기만 수정.

## 4. 에러 알림 워크플로 연결 (NFR-8 / AC-NFR8.1)

발송·조회 실패가 침묵하지 않도록 Error Trigger를 건다.

1. `n8n/error-handler-workflow.json` 임포트 → **Gmail 실패 알림** 노드에 2단계의 자격증명 연결
2. 이 워크플로를 **Active ON** (Error Trigger는 활성 상태여야 동작)
3. **본체 워크플로** → Settings(⋯) → **Error Workflow** → "메일 레이더 — 에러 알림" 선택
4. 효과: 본체가 어느 노드에서든 실패하면 실패 알림 메일이 자동 발송(워크플로명·실패 노드·오류 메시지·실행 로그 링크 포함)

## 5. 수동 테스트 (배포 전 필수 검증)

본체 워크플로 우상단 **Execute Workflow**(수동 실행은 코드상 최근 48시간 창) 후 메일함 확인:

| 검증 | 보는 곳 | 합류명세서 |
|---|---|---|
| 본문 정적표가 표로 보이는가(코드 아님) | 메일 본문 | AC-8.1 |
| 첨부 대시보드 탭·검색·카드 펼침 동작 | `inbox-YYYYMMDD.html` | AC-UI.1/UI.3 |
| 제목/발신자에 `<b>x</b>` 든 메일이 텍스트로 표시(실행 X) | 대시보드 | AC-SEC.1 (XSS) |
| 수신 0건 창에서도 "메일 없음" 안내 메일이 오는가 | 메일 수신 | **AC-3.2 (주의: 0건이면 노드 스킵 가능)** |
| 발신 메일이 결과에 섞이지 않는가 | 대시보드 | AC-3.1 |

- 본문이 raw HTML로 보이면 → 발송 노드 메시지 타입을 **HTML**로 지정.
- **AC-3.2 위험**: n8n은 입력 0건이면 노드를 건너뛸 수 있음. 0건 메일이 안 오면, 조회 노드 뒤 "항상 1건 보장" 처리 필요(코드 수정 시 SRS로 추적).

## 6. 타임존 · 활성화

1. 본체 Settings → **Timezone = Asia/Seoul** 확인(JSON에 이미 설정)
2. 모두 정상이면 본체 우상단 **Active ON**
