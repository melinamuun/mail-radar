# 아키텍처 — 수신 메일 대시보드 자동화

> SRS의 FR/NFR을 실행 구조로 매핑한다. 데이터 흐름과 분기 로직(Compute Window)을 고정한다.

## 1. 구성요소 + 데이터 흐름

```
[Schedule  0 6 * * 1,5  TZ=Asia/Seoul]            FR-1
      │
      ▼
[Code: Compute Window]                            FR-2
   요일 판별 → after/before(ISO·epoch) 계산
   출력: Window 객체(§데이터모델 4.1)
      │
      ▼
[Gmail: 수신 조회]                                 FR-3
   getAll, simple=false, returnAll
   q=in:inbox + receivedAfter/Before
      │
      ▼
[Code: Build Dashboard]                           FR-4·5·6·7·8
   레코드화 → 분류 → 정렬(action 최상단)
   → ① 인터랙티브 HTML(첨부)  ② 정적 요약(본문)
      │
      ▼
[Gmail: 발송(본인)]                                FR-9
   to=selfEmail, subject=요약, body=정적표, attach=대시보드.html
```

- **노드 ↔ FR 매핑**: Schedule=FR-1, Compute Window=FR-2, Gmail 조회=FR-3, Build Dashboard=FR-4~8, Gmail 발송=FR-9.
- **이메일 본문** = JS 없는 정적 요약표(NFR-4). **첨부** = 검색·필터 되는 인터랙티브 대시보드(FR-7).
- 분류 로직은 Build Dashboard의 키워드 규칙으로 이식(런타임 LLM 없음, NFR-3).
- HTML 템플릿은 워크플로에 base64로 내장(외부 의존 0, NFR-3).

## 2. Compute Window 분기 순서도 (FR-2)

```
                    ┌─────────────────────────┐
                    │ now(KST) → 요일(dow) 판별 │
                    └───────────┬─────────────┘
                                │
         ┌──────────────────────┼──────────────────────┐
         ▼                      ▼                      ▼
   dow == 1 (월)          dow == 5 (금)           그 외 (수동)
   end = 오늘06:00         end = 오늘06:00          end = 오늘06:00
   start = end - 3d        start = end - 4d         start = now - 48h
   (지난 금06:00)          (이번 월06:00)            (최근 48시간)
   runType=주말분          runType=주중분           runType=수동
         └──────────────────────┼──────────────────────┘
                                ▼
              start/end → ISO + epoch 변환, 라벨 생성
              출력: { q, startISO, endISO, end, runType,
                      rangeLabel, runDateLabel, selfEmail }
```

- 06:00 KST = `(06-09)h UTC`. `Date.UTC(Y,M,D,6-9,0,0)`로 경계 epoch를 직접 계산(NFR-1, 상대값 금지).
- 월·금 경계가 금06:00에서 맞물림: 한쪽은 포함, 한쪽은 배타 → 빈틈·중복 없음(NFR-6).

## 3. Build Dashboard 내부 단계 (FR-4~8)

```
items(Gmail) ─▶ [필터: SENT-only 제외] ─▶ [레코드화 FR-4]
            ─▶ [분류 classify() FR-5] ─▶ [정렬 rank FR-6]
            ─▶ 분기
                 ├─▶ [인터랙티브 HTML 생성 FR-7] → binary(첨부)
                 └─▶ [정적 요약표 생성 FR-8]    → json.summary(본문)
```

- `classify(name,email,subj)`: 보안 → 학습 → 기회 → 계정 → 뉴스 순으로 패턴 검사, 미적중 시 action/high 격상.
- 정렬 키: (action 여부, prio rank, date desc).
