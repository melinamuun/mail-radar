## 2. 레이아웃 영역 (위→아래, `.wrap` max-width 980px 중앙 정렬)

```
┌───────────────────────────────────────────────┐
│ header  · eyebrow(모노 대문자) · h1 · sub        │
├───────────────────────────────────────────────┤
│ stats   · 4칸 그리드 [전체][확인필요][안읽음][뉴스] │
├───────────────────────────────────────────────┤
│ controls· 검색 입력(돋보기 아이콘 + placeholder)   │
├───────────────────────────────────────────────┤
│ tabs    · [전체] [확인필요·N] [계정·N] … (pill)    │
├───────────────────────────────────────────────┤
│ list    · 메일 카드 세로 스택                      │
├───────────────────────────────────────────────┤
│ footer  · 자동생성 메타(모노, 중앙)                │
└───────────────────────────────────────────────┘
```

플레이스홀더: `{{TITLE}}` `{{EYEBROW}}` `{{HEADING}}` `{{SUBTITLE}}` `{{FOOTER}}` 는 Build Dashboard가 치환(FR-7).

## 3. Breakpoint Map

브레이크포인트는 **1개**(`max-width:560px`)뿐이다. 그 외는 980px 중앙 정렬 유동.

| 구간 | stats 그리드 | h1 | `.time`(카드 시간) | 비고 |
|---|---|---|---|---|
| **모바일** ≤ 560px | 2열 | 22px | 숨김(`display:none`) | 좁은 폭 대응 |
| **기본** 561 ~ 980px | 4열 | 26px | 표시 | `.wrap` 유동 |
| **와이드** > 980px | 4열 | 26px | 표시 | `.wrap` 980 고정·중앙 |

- 카드·탭·검색은 모든 구간에서 `flex-wrap`으로 자연 줄바꿈.
- `viewport` 메타 설정됨(`width=device-width, initial-scale=1`).

## 4. 컴포넌트 사양

### 4.1 Stat 카드 (`.stat`)
- 4종: 전체 / 확인필요(`.alert`, 숫자 `--action`) / 안읽음(`.unread`, 숫자 `--unread`) / 뉴스레터.
- 숫자는 모노스페이스 24px, 라벨 11px `--ink-soft`.

### 4.2 Tab (`.tab`, pill)
- `전체` + 데이터에 존재하는 카테고리만 동적 노출(카운트 0이면 숨김).
- 활성 탭 `.on`: 배경 `--ink`, 글자 흰색. 좌측 `.dot`은 카테고리 색.
- 카운트 `.cnt`는 모노.

### 4.3 메일 카드 (`.mail`) — 핵심
- 좌측 3px 보더가 분류 색을 표시. **`prio="high"`(=action)는 `--action`으로 덮어씀**(데이터 속성 우선순위).
- 1행(`.mrow1`): [안읽음 점] · 발신자(`.from`, 600) · 분류 배지(`.badge`) · 시간(`.time`, 우측 정렬·모노).
- 2행: 제목(`.subj`). 안읽음이면 600.
- 3행: snippet(`.snip`). 닫힘 상태에선 1줄 말줄임(`nowrap`).
- 숨김 영역: 발신 주소(`.email-addr`) — **열림 상태에서만 표시**.

### 4.4 상태 표현
| 상태 | 클래스 | 표현 |
|---|---|---|
| 안읽음 | `.mail.unread` | 파란 점 + 제목 굵게 |
| 펼침 | `.mail.open` | snippet 전체 줄바꿈 + 발신주소 노출 |
| 빈 결과 | `.empty` | "조건에 맞는 메일이 없습니다." 중앙 표시 |

## 5. 접근성·표시 규칙

- 시간은 `toLocaleString("ko-KR", {timeZone:"Asia/Seoul", hour12:false})` — KST 자동 변환(FR-7 AC).
- 검색 입력 포커스 시 `--accent` 2px 아웃라인.
- (개선 여지) 탭·카드에 키보드 포커스·ARIA 역할 없음 → 향후 보강 항목.
